# Benchmark measurement and traversal review — 2026-09-12

Tracking: hostvaultio/platform platform-49mr and platform-4kur.1.

Correctness review covers the PR against origin/main. Paper window labels cannot
enter measurements, metric counts are separate, and a maximum is not labelled a
percentile. Missing timing or invalid population/movement/travel/observation
coverage prevents a positive capacity headline. The CLI preserves failed results
and stops the ramp with status 2.

The terrain navigator bounds planning, uses changing bearings and shortens failed
waypoints. Safe three-block drops and separately permitted leaf removal address
reproduced stone-pocket and canopy stalls. The small client collision-clearance
adjustment is restricted to 1.21.11; other protocols retain their dimensions.
Planning errors and stalls cause another route attempt without teleport recovery.
Shutdown removes navigation listeners and timers.

Security review: leaf removal defaults off and requires boolean permission.
Planning retains the pathfinder's existing safety checks and excludes non-leaf
blocks. A second guard reads the current block immediately before invoking dig,
so a stale plan referring to a replaced block cannot bypass that check. No
scaffolding, towers or block placement is enabled. Dig outcomes snapshot the
original block name before the library mutates its block object. The wrapper is
restored on stop without overwriting a later owner of the method. Lifecycle
scripts are disabled for locked dependency installation in CI.

RCON passwords remain private input and are redacted from JSON and dry runs.
Workload observations contain positions and action outcomes, not credentials.
Live fixtures use an internal network without published ports and disposable
worlds; neither retained game configuration nor node admission is changed.

Validation includes parser/coverage regressions, failed and disconnected workloads,
legacy records, obstacle replanning, finite retries, collision-version scope,
non-leaf refusal, replaced planned blocks, cancellation and wrapper restoration.
Platform PR790 records the exact live candidate hashes, controlled comparisons,
full workload results and cleanup. Local tests are not evidence of node density.

Limits: simulated traversal and leaf clearing do not reproduce building, combat,
redstone or plugin-heavy play. Qualification is a minimum workload check, not proof
of realistic play or sufficient spatial separation. RCON windows overlap and do
not provide per-tick percentiles. The generator's own utilization must be included
in contention analysis. Fresh-world generation differs from warmed-world play.

Server-observed movement follow-up (2026-09-13): client corrections can inflate
predicted travel, so RCON mode now samples the server's own player positions.
The command is fixed and read-only, with no interpolated identifiers or world
mutation. Parsed responses must be complete, finite and unique. Only this swarm's
positions are retained. Unsupported, truncated or delayed responses invalidate the
observation, and a missing read resets movement history. Sampling uses a separate
connection, awaited reads and real timestamps; skipped time is not filled with
synthetic catch-up observations. Connection shutdown drains any pending query.
Time-packet mode rejects changing or missing correction counters. Position source
and detailed errors are included in reports; private exception text is not retained.

Correctness regressions cover the actual concatenated Paper response, client-only
phantom movement, missing players, vertical-only changes, stale history, delayed
reads, disconnections and overlapping requests. The controlled diagnostic records
19–20 server-moving clients throughout its measured window despite client position
corrections. The final CLI acceptance is recorded separately in platform PR790;
neither a successful observer nor one server validates aggregate node capacity.

The final CLI live run used 43 tests and passed with 20 connected clients, minimum
19 server-moving clients across 25 observations, all 20 spanning at least 16 blocks,
119 timing samples, 20 TPS and mean rolling MSPT 11.44 ms. Final review additionally
rejects non-finite/invalid timing configuration before the observation loop (44
offline tests). These added invalid-input guards and explanatory copy are beyond
the preserved live candidate; the tested valid configuration takes the same path.
